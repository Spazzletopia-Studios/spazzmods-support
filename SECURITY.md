# Security

**Do not open a public issue for a security problem.** Issues here are public
from the moment you press the button.

## How to report one

- On GitHub: open the **Security** tab of this repository and choose
  **Report a vulnerability**. Only Spazzletopia Studios sees it.
- Or message Spazzletopia Studios on
  [Patreon](https://www.patreon.com/c/SpazzletopiaStudios).

## What counts

- A module that can be made to run code it should not, or to write to a world
  in a way its own permissions forbid.
- A way to read another person's data at the table through a module socket.
- Anything that lets a person who is not a supporter take Supporter files, or
  that exposes the download service itself.

## What to expect

You get an answer within three days. A confirmed problem is treated as P0: the
fix goes out as soon as it is ready, and the release notes say what was wrong
without handing anyone a recipe. If you want credit in those notes, say so, and
say what name to use.

**Never put a password, a token, a licence key, or a payment detail in a
report.** Nobody from SpazzMods will ask you for one.
