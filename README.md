# SpazzMods Support

One place to report a problem, ask a question, or suggest something, for every
SpazzMods module for Pathfinder 2e on Foundry VTT.

**[Report a bug](https://github.com/Spazzletopia-Studios/spazzmods-support/issues/new?template=bug.yml)**
· **[Install or download problem](https://github.com/Spazzletopia-Studios/spazzmods-support/issues/new?template=install.yml)**
· **[Ask a question](https://github.com/Spazzletopia-Studios/spazzmods-support/issues/new?template=question.yml)**
· **[Suggest something](https://github.com/Spazzletopia-Studios/spazzmods-support/issues/new?template=idea.yml)**

Free module or Supporter module, it all comes here. You do not need a membership
to post. You never need to give a password, a payment detail, or an account
email to get help, and nobody from SpazzMods will ask you for one.

## Do these two things first

1. **Take the latest version.** Open the SpazzMods Hub inside Foundry, or run
   the SpazzMods Installer. A good share of reports are already fixed.
2. **Find out whose bug it is.** Turn off your other modules, leave the SpazzMods
   one on, and try again. If the problem stops, turn the others back on one at a
   time and tell us which one brings it back.

Then open one of the forms above. Each form asks for versions and steps, because
a report without them turns into a week of questions.

## Tested against

| Foundry VTT | Pathfinder 2e system |
| --- | --- |
| v13 and v14 | 8.x |

Older versions are not tested, and a fix for them is not promised.

## How fast you hear back

| Priority | What it means | When it is fixed |
| --- | --- | --- |
| **P0** | Data loss, a security problem, or downloads and the catalog are down | Now. Other work stops. |
| **P1** | A main feature is broken, or a Pathfinder rule gives the wrong result | The next patch, usually within two days |
| **P2** | An edge case, or something looks wrong | The weekly maintenance batch |
| **P3** | An idea or a request | Goes on the roadmap |

New issues are sorted on Mondays and releases go out on Fridays. A P0 waits for
neither. The detail is in [SUPPORT.md](SUPPORT.md).

## Not a support question

- **Membership, billing, a tier change, or anything with your personal details:**
  message Spazzletopia Studios on [Patreon](https://www.patreon.com/c/SpazzletopiaStudios).
  Never post those here. Issues are public and search engines index them.
- **A security problem:** read [SECURITY.md](SECURITY.md) and report it
  privately. Do not open a public issue.
